Una aplicación completa de dashboard de KPIs construida con FastAPI y React, que incluye autenticación JWT, operaciones CRUD y visualización de datos en tiempo real.

## 🎯 Características Principales

- 🔐 **Autenticación JWT** segura
- 📈 **Dashboard de KPIs** interactivo
- 🗃️ **Operaciones CRUD** completas
- 📊 **Visualización de datos** con gráficos
- 🔒 **Autorización basada en roles**
- 📱 **Diseño responsive**
- 🐳 **Dockerizado** para fácil despliegue

## 🛠️ Tecnologías Utilizadas

### Backend
- **FastAPI** - Framework web moderno y rápido
- **PostgreSQL** - Base de datos relacional
- **SQLAlchemy** - ORM para Python
- **JWT** - Autenticación con tokens
- **Pydantic** - Validación de datos
- **Alembic** - Migraciones de base de datos

### Frontend
- **React 18** - Biblioteca de interfaz de usuario
- **React Router** - Navegación
- **Axios** - Cliente HTTP
- **Chart.js** - Gráficos y visualizaciones
- **Tailwind CSS** - Framework de CSS
- **React Context** - Gestión de estado
